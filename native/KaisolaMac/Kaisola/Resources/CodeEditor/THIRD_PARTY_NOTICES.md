# Code editor third-party notices

`editor.bundle.js` is generated by `npm run code-editor:bundle` from the exact
versions recorded in the repository's `package-lock.json`.

The bundle includes CodeMirror 6 packages maintained by Marijn Haverbeke and
contributors, their Lezer parser packages, and the small runtime dependencies
resolved by those packages. Those components are distributed under the MIT
License. Copyright and license texts remain available in each pinned package's
`LICENSE` file under `node_modules` after `npm ci`.

Rollup and its plugins are build-time tools and are not included in the shipped
JavaScript bundle.
