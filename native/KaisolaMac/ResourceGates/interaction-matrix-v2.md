# Native workspace interaction matrix v2

This is the current evidence ledger for the native product. It distinguishes
repeatable contracts from visual judgment and from tests that genuinely need a
signed account, physical network change, or real iPhone.

- `AUTOMATED PASS`: a deterministic repository gate covers the claim.
- `ISOLATED LIVE PASS`: the real AppKit/SwiftUI surface was exercised in a
  broker-free copied app; this is visual/interaction evidence, not distribution.
- `SIGNED PRODUCTION PASS`: the exact Developer-ID artifact completed the named
  production route.
- `PARTIAL`: meaningful evidence exists, but the named human/hardware check is
  still required.
- `OPEN`: no adequate current evidence.

## Required commands for a candidate

Run the focused contracts that own the changed row, then the full native suite,
`npm run site:contract`, `npm --prefix relay test`, the native release preflight,
deep signature verification, launch smoke, and broker continuity probe. For a
Link milestone also run `npm run companion:web-link-probe` and the signed
`companion:native-browser-e2e-probe` against the candidate executable.

Do not promote `ISOLATED LIVE PASS` to signed distribution evidence, and do not
promote deterministic network simulation to a physical Wi-Fi/cellular result.
