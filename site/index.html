Kaisola Changelog GitHub

The fully Mac‑native GUI for coding agents.

Kaisola hosts the agent CLIs you already use — Claude Code, Codex, and any CLI you register — in durable terminals and rich chat, organized by project, with an iPhone companion for approving from your pocket. The interface is the product; the agent runtimes stay the vendors' own.

Download for Mac View on GitHub free download · macOS 14+ · Apple Silicon

Agents, first‑class

Terminal-hosted CLI agents and rich chats sit side by side in every project. Switch the account or the model mid-conversation with the transcript intact, and a cross-project attention center collects everything that needs you, with per-event notification rules.

terminals + chat · switch model mid-conversation · attention center

Many subscriptions, one app

Sign in to multiple Claude and Codex accounts. See each plan's usage, reset windows, and per-turn cost — and get told before you start a session on a spent account.

usage meters · reset windows · per-turn cost

An IDE around the agents

File tree, editable Markdown and file previews, syntax highlighting, Git panels, project-scoped MCP configuration, a command palette, multi-window and split layouts — and terminals that reopen in place after a relaunch.

file tree · git · MCP · command palette · native terminals

Native all the way down

SwiftUI and AppKit, a measured glass aesthetic over your own desktop wallpaper, Sparkle updates. No Electron, no web-view shell.

SwiftUI + AppKit · Sparkle updates · zero Electron

Yours to extend

Validated registries for custom terminal themes, syntax grammars, and preview mappings — and custom agents, including chat-capable ACP adapters installed as pinned, integrity-verified code.

themes · grammars · preview mappings · custom agents
